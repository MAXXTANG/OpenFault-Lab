# Contributing

OpenFault Lab is at the feasibility stage. Useful first contributions are official-document checks, sensor compatibility research, and reproducible bench-test designs.

Before adding a feature, describe the problem, the intended behavior, and how it can be verified in an issue or pull request. Keep contributions small enough to review.

For hardware claims, include the exact part, board revision, document version, and relevant official reference. For software changes, list the commands actually run and distinguish host tests from STM32 hardware tests. Report limitations and failures as well as successes.

Only submit material you have permission to publish. Identify third-party components and their licenses. Do not include personal application records, proprietary designs, credentials, or recordings of people. Dataset releases need explicit permission and separate licensing.
